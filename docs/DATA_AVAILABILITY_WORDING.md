# Proposed Data Availability wording (not yet inserted into the paper)

## While the repository remains private

"The reference implementations, validation scripts, and synthetic test data generated for this study are available from the corresponding author upon reasonable request during peer review. The complete propagation-loss matrices underlying the principal published examples were not available for this work and are not included in the validation dataset. The repository will be made publicly accessible before publication, subject to the required release approvals."

Review the journal's final research-data and software requirements before submission. This wording is suitable only if the authors can actually provide the indicated files to editors/reviewers.

## Once the public GitHub release has been verified

"The reference implementations, synthetic-instance generators, and scripts and records used for the numerical validation are available at https://github.com/ueda1984/propagation-dp-baselines (revision: [PUBLICLY ACCESSIBLE COMMIT OR TAG]; archived DOI: [ADD IF AVAILABLE]). The validation instances are synthetic local-cost data for the finite-memory objective class, not reconstructions of the complete propagation-loss matrices of the principal published examples; those matrices were not available for this work. The structural operation counts follow from the formulas stated in the text."

Before replacing the paper's Data Availability statement: confirm anonymous access, the exact hash/tag, the validation record matching that revision, and whether any long-term archive/DOI was actually minted. Do not claim Zenodo publication or a DOI until verified.
