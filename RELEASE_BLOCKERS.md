# Required before making this repository public

1. Obtain authors'/contributors' agreement to release the source and test records.
2. Choose a license after checking any employer/institution/funding restrictions;
   replace `LICENSE_DECISION_REQUIRED.md` with the actual `LICENSE`.
3. Confirm software citation authors (not necessarily identical to the
   manuscript author list), and complete `CITATION.cff`.
4. [DONE FOR STAGING] A private `ueda1984/propagation-dp-baselines` repository
   was created and the reference files were checked for upload. Before public
   release, verify the public URL and create an immutable release tag or cite a
   full commit SHA.
5. Execute installation and smoke/edge tests from a clean clone; optionally
   rerun the full verification campaign on that exact revision.
6. Update the manuscript's Data Availability statement to the verified
   repository URL and immutable tag/commit; consider archiving a release on Zenodo.
7. Do not represent synthetic tests as reproductions of published loss matrices.
